# Manage git repo in vscode
- Open git repo in vscode
    - Copy repo link in github
    - Ctrl + shift + P to open Command Pallete
    - Type Git: Clone
    - Paste the repo link url, press enter

- Push it back to github from vscode
    - Go to Source Control or Ctrl + Shift + G
    - Write message in the text box
    - Click commit
    - Click push
    - Refresh github repo to see the changes
